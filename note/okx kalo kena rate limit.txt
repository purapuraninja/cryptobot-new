Tambahkan/ubah ini di .env VPS:
OKX_WEB3_MAX_SYMBOLS=30
OKX_WEB3_CACHE_TTL_SECONDS=300
OKX_WEB3_TIMEOUT_SECONDS=10
OKX_WEB3_MIN_INTERVAL_MS=250
OKX_WEB3_429_MAX_RETRIES=2
OKX_WEB3_429_BASE_DELAY_MS=1000
ONCHAIN_CONTEXT_MAX_SYMBOLS=0
Fungsinya:
OKX_WEB3_MAX_SYMBOLS=30
Maksimal symbol yang dicoba enrich OKX per scan.
OKX_WEB3_CACHE_TTL_SECONDS=300
Cache hasil OKX 300 detik. Kalau bot scan tiap 5 menit, tidak spam request untuk token yang sama dalam window itu.
OKX_WEB3_TIMEOUT_SECONDS=10
Timeout per request OKX.
OKX_WEB3_MIN_INTERVAL_MS=250
Jeda minimal antar request OKX. Kalau kena rate limit, naikkan misalnya:
OKX_WEB3_MIN_INTERVAL_MS=500
atau:
OKX_WEB3_MIN_INTERVAL_MS=1000
OKX_WEB3_429_MAX_RETRIES=2
Retry kalau OKX balas HTTP 429.
OKX_WEB3_429_BASE_DELAY_MS=1000
Base delay retry 429. Retry pakai exponential backoff:
retry 1: 1s
retry 2: 2s
retry 3: 4s, kalau max retries dinaikkan
ONCHAIN_CONTEXT_MAX_SYMBOLS=0
0 berarti semua symbol market_data yang berhasil di-fetch bot dikirim ke on-chain/OKX context. Kalau mau batasi, isi angka:
ONCHAIN_CONTEXT_MAX_SYMBOLS=15
Kalau kena rate limit, setting aman:
OKX_WEB3_MAX_SYMBOLS=15
OKX_WEB3_MIN_INTERVAL_MS=1000
OKX_WEB3_429_MAX_RETRIES=3
OKX_WEB3_429_BASE_DELAY_MS=2000
OKX_WEB3_CACHE_TTL_SECONDS=600
